# Leonida Trophy Guide — GTA VI · 55 PS5 Trophies

An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 (1 platinum, 2 gold, 6 silver, 46 bronze; 28 hidden; 0 online). Built for the [gta6-trophy-guide-01 bounty on make.fun](https://make.fun/bounty/gta6-trophy-guide-01).

## What it is

- **Checklist tracker** — every trophy with its official name, description and grade; tick earned ones off and progress is saved in the browser (localStorage), with export to a JSON file and import back.
- **Cited guides** — each trophy has a guide written in this guide's own words, with its sources named beside it (PowerPyx Trophy Guide & Roadmap, Exophase trophy list).
- **Roadmap to the platinum** — three steps (story 60–80 h, 100% checklist ~100 h, Strangers & Freaks + cleanup ~10 h), the chapter order, and the full 100% checklist breakdown.
- **Missable flags** — exactly one trophy is potentially missable: Positive Mental Attitude (a Chapter 1 meditation). Five trophies whose unlock method was not yet confirmed at launch are labelled "Method not yet confirmed" rather than guessed.
- **Filters** — by kind (Story, Missable, Collectibles, Activities, Online), by grade, by earned status, and free-text search. The Online filter is honestly empty: the game has no online trophies.
- **Spoiler setting** — on by default: story trophies stay hidden ("Hidden Story Trophy") until earned.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Static files under `app/` — no build step, no network, no external assets. Open `app/index.html` from any static server with `app/` at its root.
